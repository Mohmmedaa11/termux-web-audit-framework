# مصفوفة التغطية

لا توجد أداة واحدة تكتشف جميع الثغرات. التغطية تعتمد على صلاحيات الفحص، المصادقة، إعدادات التطبيق، جودة القوالب، ووجود مراجعة يدوية.

| المجال | التغطية الآلية الحالية | الحد أو الحاجة إلى تحقق يدوي |
|---|---|---|
| ترويسات HTTP | CSP، HSTS، X-Content-Type-Options، Referrer-Policy، Permissions-Policy، Server | وجود الترويسة لا يعني أنها صحيحة أو فعالة |
| الكوكيز | Secure، HttpOnly، SameSite، عند ظهور Set-Cookie | لا يختبر منطق الجلسات أو تثبيت الجلسة |
| CORS | يرصد wildcard في Access-Control-Allow-Origin | لا يختبر كل مسارات origins أو preflight |
| TLS | الإصدار، cipher، سلسلة الثقة، قرب انتهاء الشهادة | لا يستبدل مراجعة إعدادات TLS الشاملة |
| DNS | عناوين A/AAAA ووجود حل DNS | لا يثبت ملكية الأصل أو عدم وجود takeover |
| اكتشاف التقنية | httpx، WhatWeb، Nmap، Nikto، ZAP Baseline عند توفرها | البصمات قد تكون خاطئة أو غير مكتملة |
| قوالب ومؤشرات معروفة | Nuclei بأولوية منخفضة إلى عالية ومعدل محدود | النتائج تحتاج تحققًا، ولا تُشغّل قوالب استغلالية |
| أخطاء الخادم | استجابات 5xx وبعض المؤشرات النصية | لا يحلل سجلات الخادم أو منطق الأعمال |
| المصادقة والتفويض | غير آليًا في الوضع الافتراضي | يجب اختبار RBAC، IDOR، الجلسات، وMFA بتصريح منفصل |
| منطق الأعمال | غير آليًا | يحتاج سيناريوهات واختبارًا يدويًا |
| SQLi/XSS/RCE | لا ينفذ استغلالًا | لا يعتبر غياب التنبيه دليل أمان |
| رفع الملفات، SSRF، CSRF | مؤشرات محدودة فقط عبر الأدوات عند توفرها | تحتاج حالات اختبار مصرحًا بها ومراجعة يدوية |

## ما يجب إضافته إلى خطة الاختبار

للوصول إلى تقييم مهني، اربط التقرير بمراجعة كود، اختبار مصادقة وتفويض، فحص التبعيات، مراجعة إعدادات السحابة، واختبار يدوي ضمن بيئة staging. لا ترفع معدل الطلبات أو تضف خيارات هجومية إلى ملفات التشغيل الثابتة دون مراجعة مكتوبة للتفويض والأثر.
