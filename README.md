# Termux Web Audit Framework

إطار خفيف وآمن نسبيًا لفحص مواقع **تملكها أو لديك تصريح مكتوب لاختبارها** من Termux. الهدف هو جمع مؤشرات دفاعية منخفضة التأثير، توحيد النتائج، وتقدير الخطورة دون استغلال الثغرات.

> **تنبيه قانوني:** لا تستخدم هذا المشروع ضد أهداف عامة أو دون تفويض. أنت مسؤول عن النطاق، معدل الطلبات، والالتزام بالقوانين وسياسات مزود الخدمة.

## ما الذي يفعله؟

- يفرض قائمة نطاقات مسموحة في `config/scope.txt`.
- يفحص HTTP/HTTPS والاستجابات وإعادة التوجيه.
- يتحقق من ترويسات الأمان الشائعة، ملفات `robots.txt` و`security.txt`، ومؤشرات TLS الأساسية.
- يدعم تشغيل أدوات اختيارية مثبتة محليًا مثل `nmap`, `nikto`, `nuclei`, `whatweb`, و`wafw00f`، لكن لا يشغلها إلا عند طلب صريح.
- يحول النتائج إلى JSON وMarkdown مع درجة خطورة تقريبية قابلة للتدقيق.
- يحافظ على سجل تشغيل، مهلة، وعدد طلبات منخفض.

## التثبيت على Termux

```bash
pkg update
pkg install -y python git curl
# اختياري، ثبّت ما تحتاجه فقط:
pkg install -y nmap
# أدوات إضافية يمكن تثبيتها من مصادرها الرسمية بعد مراجعة تراخيصها:
# nuclei, nikto, whatweb, wafw00f

git clone <رابط-المستودع>
cd termux-web-audit
chmod +x audit.py
```

## الاستخدام الآمن

1. أضف النطاقات المصرح بها فقط:

```bash
printf '%s\n' 'example.com' 'staging.example.com' > config/scope.txt
```

2. شغّل الفحص الأساسي:

```bash
python audit.py scan --target https://staging.example.com --scope config/scope.txt --out reports
```

3. لتفعيل أداة خارجية، استخدم الخيار الصريح، وراجع أثرها أولًا:

```bash
python audit.py scan --target https://staging.example.com \
  --scope config/scope.txt --out reports --tool nmap
```

الأدوات المدعومة: `nmap`, `nikto`, `nuclei`, `whatweb`, `wafw00f`. لا توجد خيارات استغلال أو brute force في هذا الإطار.

## تفسير الدرجات

- **Critical:** مؤشر قوي على خطر شديد؛ يحتاج إيقاف التعرض والتحقق اليدوي الفوري.
- **High:** ضعف مهم قد يسمح بتأثير كبير عند جمعه مع عوامل أخرى.
- **Medium:** إعداد أو كشف معلومات يحتاج معالجة مخططة.
- **Low / Info:** تحسينات أو ملاحظات سياقية.

الدرجات ليست إثباتًا لوجود ثغرة. يجب التحقق يدويًا، وتوثيق التصريح، وإعادة الاختبار بعد الإصلاح.

## المخرجات

- `report.json`: نتائج منظمة قابلة للمعالجة.
- `report.md`: ملخص عربي/إنجليزي مناسب للمراجعة.
- `raw/`: مخرجات الأدوات الخارجية عند استخدامها.

## حدود مقصودة

هذا المشروع لا ينفذ exploit، ولا يتجاوز المصادقة، ولا يجمع كلمات مرور، ولا يفحص عناوين غير موجودة في النطاق، ولا يطلق فحصًا واسعًا تلقائيًا. استخدم أدوات كل طرف وفق ترخيصها وإعداداتها، وقلل المعدل بما يناسب بيئتك.
