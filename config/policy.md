# سياسة الاستخدام

قبل كل تشغيل، يجب أن يتوفر تصريح واضح يحدد الأهداف، المدة، معدل الطلبات، والأدوات المسموح بها. استخدم بيئة staging متى أمكن، وحدد جهة اتصال للطوارئ، وتوقف فورًا عند ظهور أثر على التوافر أو بيانات المستخدمين.

الفحص الافتراضي دفاعي ومنخفض التأثير. تفعيل أي أداة خارجية مسؤولية المشغل، ويجب مراجعة خياراتها وعدم إضافة خيارات هجومية أو تجاوزات للمصادقة.
